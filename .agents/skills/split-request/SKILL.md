# 자료요구서 문항 분리

이 프로젝트의 `원문/*.pdf`를 읽어 루트의 `split.py` 하나로 `data/문항목록.csv`를 생성한다. 원문 PDF와 기존 데이터는 읽기 전용으로 취급한다.

## 시작 전 확인

1. 루트 `AGENTS.md`에 따라 `PROGRESS.md`, `CONTEXT.md`, `처리지침.md` 제2장을 먼저 읽는다. `99_완성본_잠금`은 열거나 참고하지 않는다.
2. 다음 명령으로 `pypdf` 설치 여부를 먼저 확인한다.

   ```powershell
   python -c "import pypdf; print(pypdf.__version__)"
   ```

3. 설치되어 있지 않으면 `pip install pypdf` 명령만 사용자에게 보여 주고 허락을 기다린다. 명시적 허락을 받은 뒤에만 설치한다.
4. PDF 처리는 `pypdf`만 사용한다. 최종 처리 코드는 프로젝트 루트의 `split.py` 하나만 둔다.
5. `data/문항목록.csv`가 이미 있으면 교체된 정답 예시로 읽기만 한다. 사용자가 명시적으로 재생성을 요청하지 않은 한 먼저 덮어쓰지 말고, 새 `split.py`가 메모리에서 만드는 행과 열별로 비교한다.

## 출력 계약

- 경로: `data/문항목록.csv`
- 인코딩: `utf-8-sig`
- 열과 순서: `파일명 | 위원회 | 의원 | 제출기한 | 문항번호 | 요구내용 | 세부항목 | 비고`
- 기존 `data/` 파일과 원문 PDF는 수정·삭제·덮어쓰지 않는다. 출력 파일이 이미 있는 경우에는 위 시작 전 확인의 비교·승인 조건을 따른다.

## 분리 규칙

페이지 순서대로 `extract_text()` 결과를 연결해 처리한다. 페이지 경계에서 문항이 이어질 수 있다.

1. 첫 번째 유효 줄 `○○위원회 ○○ 의원실 자료요구서`에서 위원회와 의원을 추출한다.
2. `수신: … 제출기한: 2026. 10. 12.(월) 18:00까지` 형식에서 날짜를 추출해 `YYYY-MM-DD`로 저장한다.
3. `수신:`, `담당 보좌관:`, `끝.` 줄은 어떤 출력 열에도 넣지 않는다. 보좌관 이름과 연락처도 저장하지 않는다.
4. 줄 맨 앞이 `숫자.`이면 새 문항이다. 숫자는 `문항번호`, 나머지는 `요구내용`이다.
5. `가.`, `나.` 줄은 같은 문항의 `세부항목`에 줄바꿈으로 누적한다.
6. `※` 줄은 같은 문항의 `비고`에 줄바꿈으로 누적한다.
7. 그 밖의 줄은 바로 앞 항목인 `요구내용`, `세부항목`, `비고` 중 하나에 이어 붙인다.
8. 연속 공백은 한 칸으로 정리하되 `가.`, `나.`, `※` 표시는 보존한다.

현재 교체된 `data/문항목록.csv`가 존재하면, 위 규칙으로 만든 결과가 행 수뿐 아니라 파일명·메타데이터·문항번호·본문·세부항목·비고까지 완전히 같아야 한다. 차이가 있으면 CSV를 정답 예시로 삼아 PDF 원문과 함께 원인을 확인하고 `split.py`를 최소 범위로 고친다. 정답 예시의 내용을 코드에 하드코딩하지 않는다.

## 실행과 확인

`split.py`를 실행한 뒤 다음 표를 반드시 제시한다.

```text
파일명 | 파일명의 문항 수 | 뽑은 문항 수 | 마지막 번호 | 번호 연속 | 일치(O/X)
```

- 파일명의 `_25문항.pdf` 같은 숫자와 추출 수를 비교한다.
- 마지막 번호가 파일명 문항 수와 같은지 확인한다.
- 번호가 1부터 마지막 번호까지 중복·누락 없이 연속인지 확인한다.
- 세 조건이 모두 맞을 때만 `일치`를 `O`로 표시한다.
- `X`가 하나라도 있으면 완료로 보고하지 않는다. PDF 추출문, 페이지 경계, 이어 붙이기 대상을 확인해 원인을 고치고 다시 실행한다.

추가로 다음을 검증한다.

- CSV 선두가 UTF-8 BOM `EF BB BF`인지 확인한다.
- 열 이름과 순서가 출력 계약과 정확히 같은지 확인한다.
- 전체 행 수와 파일별 행 수를 확인한다.
- 제출기한이 유효한 ISO 날짜인지 확인한다.
- `수신:`, `담당 보좌관:`, 보좌관 이름·연락처, `끝.`이 출력에 없는지 확인한다.
- 세부항목과 비고가 모두 있는 문항 3개를 골라 `원문 PDF 추출문 | CSV 결과` 형식으로 나란히 제시한다. 가능한 경우 서로 다른 파일의 예시를 포함한다.
- 기존 문항목록이 정답 예시라면 생성 결과와 모든 행·열이 일치하는지 확인한다.
